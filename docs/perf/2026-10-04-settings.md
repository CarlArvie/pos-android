## Changes Made
- **Parallelized SQLite Loading (`[Verified]`)**: Consolidated `getCompany`, `getStore`, and `getRegister` into a concurrent `Future.wait([ ... ])` call, eliminating sequential query roundtrips. State fields and `_isLoading = false` are set atomically in a single `setState`.
- **Eliminated `LayoutBuilder` (`[Verified]`)**: Replaced `LayoutBuilder` in `SettingsView` and `EditDiscountRulesDialog` with direct `MediaQuery.sizeOf(context).width < 420` evaluation, eliminating deferred sub-layout passes.
- **Isolated Card Repaints (`[Verified]`)**: Wrapped Business Profile, Security Settings, Discount Policies, Hardware Binding, and Danger Zone cards in `RepaintBoundary` to prevent re-rasterization cascades.
- **Ergonomics & Touch Targets (`[Verified]`)**: Enforced `>= 44dp` touch targets on all list tile actions, dialog buttons, close icons, and the preset delete button (`minWidth: 44, minHeight: 44`).
- **Mobile Keyboard & Viewport Safety (`[Verified]`)**: Wrapped dialog text fields in `SingleChildScrollView` and bounded switch dialog lists with `maxHeight: MediaQuery.sizeOf(context).height * 0.6` to prevent virtual keyboard overflows on 360dp screens.
